# ग्रामसेवक (GRAMSEVAK)
### AI-Powered Rural Healthcare Assistance & Early Risk Assessment Platform
> **"आपके स्वास्थ्य की देखभाल, आपकी अपनी भाषा में"**

ग्रामसेवक (GRAMSEVAK) भारत के ग्रामीण समुदायों के लिए विकसित एक सुगम, पारदर्शी और मोबाइल-प्रथम प्राथमिक स्वास्थ्य सहायता मंच है। यह मंच उन ग्रामीण नागरिकों की सहायता करता है जिन्हें स्वास्थ्य जानकारी, डिजिटल साक्षरता और चिकित्सा सुविधाओं तक पहुँचने में कठिनाई होती है।

---

## 🌟 प्रमुख विशेषताएं (Core Capabilities)

1. **100% देवनागरी हिंदी इंटरफ़ेस (Hindi-First Accessibility):**
   - सभी शीर्षलेख, बटन, फॉर्म लेबल, मार्गदर्शन, त्रुटि संदेश और रिपोर्ट सरल, ग्रामीण बोलचाल की हिंदी में उपलब्ध हैं।
   - वैज्ञानिक व चिकित्सीय शब्दों (जैसे BP, SpO2, Heart Rate) के साथ सरल हिंदी अनुवाद और समझाई गई परिभाषाएं दी गई हैं।

2. **पारदर्शी एवं प्राथमिक स्वास्थ्य जोखिम मूल्यांकन इंजन (Transparent Clinical Engine):**
   - किसी ब्लैक-बॉक्स या मनगढ़ंत एआई मॉडल के बजाय वास्तविक, पारदर्शी और चिकित्सकीय रूप से समीक्षित नियमों पर आधारित।
   - प्राथमिकता क्रम:
     1. **आपातकालीन चेतावनी संकेत (Emergency Warning Signs - RED):** सीने का दर्द, अत्यधिक साँस फूलना, स्ट्रोक लक्षण (FAST), बेहोशी, अनियंत्रित रक्तस्राव, गंभीर गर्भावस्था संकट।
     2. **खतरनाक स्वास्थ्य माप (Dangerous Vitals - RED):** बीपी संकट (≥180/120 mmHg), हाइपोक्सिया (SpO2 < 90%), हाइपरपाइरेक्सिया (तापमान ≥ 104°F), 1 वर्ष से कम उम्र के शिशु में बुखार।
     3. **सावधानी योग्य लक्षण एवं जोखिम (Yellow Signs):** लगातार 3 दिन से बुखार, डिहाइड्रेशन का खतरा, स्टेज 2 हाइपरटेंशन, गर्भावस्था में लक्षण।
     4. **कम तात्कालिक चिंता (Green):** कोई आपात संकेत नहीं (बिना यह दावा किए कि मरीज 100% स्वस्थ है)।

3. **आपातकालीन स्क्रीनिंग प्राथमिकता (Zero-Delay Emergency Screening):**
   - किसी भी आपात संकेत पर तुरंत लाल अलर्ट बैनर और भारत की 112 / 108 हेल्पलाइन पर सीधे कॉल करने का विकल्प।
   - कोई लंबा फॉर्म भरने की बाध्यता नहीं।

4. **इंटरैक्टिव 3D मानव शरीर लक्षण दृश्य (Interactive 3D Body Avatar):**
   - Three.js आधारित 3D मानव शरीर मॉडल।
   - सामने और पीछे का दृश्य (360° रोटेशन), ज़ूम इन/आउट एवं रीसेट नियंत्रण।
   - लक्षणों के प्रभावित अंगों (सिर, छाती, पेट, बाँहें, पैर/जोड़, त्वचा) का रंगीन हाइलाइट (लाल/पीला/स्लेटी)।
   - कमजोर फोन या गैर-WebGL डिवाइसों के लिए तुरंत और स्वचालित **2D लक्षण मानचित्र (SVG Fallback)**।

5. **प्रमाणित घरेलू देखभाल पुस्तकालय (Evidence-Based Home-Care Guidance):**
   - स्वास्थ्य एवं परिवार कल्याण मंत्रालय (MoHFW), राष्ट्रीय स्वास्थ्य मिशन (NHM) एवं विश्व स्वास्थ्य संगठन (WHO) के दिशानिर्देशों पर आधारित।
   - प्रत्येक लक्षण के 6 व्यवस्थित बिंदु:
     1. क्या करना चाहिए?
     2. इसे कैसे करना चाहिए? (ओआरएस बनाने की सही विधि: 1 पैकेट 1 लीटर पानी में)
     3. इससे क्या लाभ हो सकता है?
     4. किन बातों से बचना चाहिए? (एंटीबायोटिक से परहेज, हानिकारक घरेलू नुस्खों पर रोक)
     5. कब डॉक्टर से मिलना चाहिए?
     6. तुरंत आपातकालीन चेतावनी संकेत (Red Flags)।

6. **नज़दीकी स्वास्थ्य केंद्र खोज एवं दूरी मार्गदर्शन (Healthcare Discovery):**
   - ग्रामीण स्वास्थ्य ढांचे की स्पष्ट समझ (उप-स्वास्थ्य केंद्र, PHC, CHC, जिला अस्पताल)।
   - आपातकालीन हेल्पलाइन (112, 108, 102, 104) पर एक क्लिक में सीधी कॉल।
   - उपयोगकर्ता द्वारा दर्ज किलोमीटर दूरी के अनुसार अस्पताल पहुँचने का समय मार्गदर्शन।
   - उपयोगकर्ता की सहमति पर सुरक्षित गूगल मैप्स एकीकरण।

7. **गोपनीयता एवं डेटा सुरक्षा (Privacy by Design):**
   - कोई अनिवार्य पंजीकरण या लॉगिन नहीं।
   - सारा स्वास्थ्य मूल्यांकन केवल उपयोगकर्ता के अपने डिवाइस में (Client-Side) होता है।
   - यूआरएल में कोई संवेदनशील स्वास्थ्य जानकारी नहीं जाती।
   - कोई विज्ञापन ट्रैकिंग नहीं।

## 🚀 स्थानीय स्तर पर चलाने की विधि (Local Setup & Run)

### 1. पूर्वापेक्षाएँ (Prerequisites)
- Node.js (v18 या उच्चतर)
- npm

### 2. निर्भरताएँ संस्थापित करें (Install Dependencies)
```bash
npm install
```

### 3. विकास सर्वर शुरू करें (Start Development Server)
```bash
npm run dev
```
ब्राउज़र में `http://localhost:3000` खोलें।

### 4. स्वचालित परीक्षण चलाएं (Run Automated Tests)
```bash
npm test
```
इस परियोजना में सभी 20 नैदानिक सुरक्षा परीक्षण (Clinical Safety Test Cases) सम्मिलित हैं।

### 5. प्रोडक्शन बिल्ड बनाएं (Production Build)
```bash
npm run build
```

## 🧪 स्वचालित परीक्षण परिदृश्य (Automated Clinical Tests - 20/20 Passed)

1. कोई लक्षण नहीं और सामान्य माप → हरा (GREEN - Routine)
2. 1 दिन का बुखार → पीला (YELLOW - Home Care)
3. 3 दिन से अधिक लगातार बुखार → पीला (YELLOW - Same Day Doctor)
4. गंभीर सीने में दर्द → लाल (RED - Emergency Immediate 112)
5. अत्यधिक साँस में परेशानी → लाल (RED - Emergency Immediate)
6. स्ट्रोक / लकवा के लक्षण (FAST) → लाल (RED - Emergency Immediate)
7. अति उच्च रक्तचाप संकट (BP ≥ 180/120) → लाल (RED - Crisis)
8. असामान्य हृदय गति (Tachycardia > 115 bpm) → पीला (YELLOW)
9. 1 वर्ष से कम उम्र के शिशु में बुखार → लाल (RED - Pediatric Sepsis Risk)
10. गर्भावस्था में स्वास्थ्य लक्षण → पीला (YELLOW - Same Day Consult)
11. अनुपलब्ध बीपी एवं हृदय गति → पारदर्शी अनिश्चितता सूचना
12. लक्षण रहित लेकिन अनुपलब्ध माप → 100% स्वस्थ होने का कोई झूठा दावा नहीं
13. पूरे शरीर में दर्द → सहायक प्राथमिक देखभाल
14. विरोधाभासी फॉर्म चयन → सुरक्षित समाधान
15. तापमान इकाई रूपांतरण (39°C → 102.2°F)
16. सामान्य मापों के बावजूद आपातकालीन चेतावनी → आपातकाल सर्वोच्च प्राथमिकता (RED)
17. SpO2 < 90% (गंभीर हाइपोक्सिया) → लाल (RED)
18. अति उच्च तापमान (≥ 104°F) → लाल (RED)
19. कम तात्कालिक लक्षण + उच्च तात्कालिक चेतावनी → लाल द्वारा ओवरराइड
20. समयावधि रूपांतरण (96 घंटे = 4 दिन)

## ⚕️ चिकित्सकीय अस्वीकरण एवं भविष्य की समीक्षा (Medical Disclaimer & Limitations)

ग्रामसेवक एक प्रारंभिक स्वास्थ्य सहायता और जोखिम चेतावनी मंच है। यह किसी पंजीकृत चिकित्सक (MBBS/MD) के परामर्श, आधिकारिक निदान अथवा आपातकालीन अस्पताल सेवा का विकल्प नहीं है। वास्तविक उपयोग से पहले सभी नियमों को योग्य सार्वजनिक स्वास्थ्य विशेषज्ञों द्वारा निरंतर समीक्षाधीन रखा जाना चाहिए।
